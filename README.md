# Secret Santa Breuil-Wenckowski

Site familial du Secret Santa, publié avec GitHub Pages :
https://aliciabreuil.github.io/family-secret-santa-breuil-wencko/

- `assets/` — vidéos et images.
- `firestore.rules` — règles de la base Firebase qui retient les prénoms déjà joués
  (à copier dans Firebase › Firestore › Règles).
